# 🎵 Music Controller - Squid Game Red Light, Green Light  

This is a **Python-based music controller** using **Tkinter** for the GUI and **Pygame** for audio playback. It allows users to play, pause, stop, and resume music tracks inspired by the *Squid Game* "Red Light, Green Light" concept.

## ✨ Features  
✅ **Play different tracks**:  
   - **Music (Loop)** - Plays Track A in a continuous loop.  
   - **Red Light!!!** - Stops the current track and plays Track B.  
   - **Green Light** - Stops the current track and plays Track C.  
   - **Track Auto-Switching** - When Track C finishes, it automatically starts Track A in a loop.  

✅ **Playback Controls**:  
   - **Pause**: Temporarily halts playback.  
   - **Resume**: Continues playback from the paused state.  
   - **Stop**: Stops all music immediately.  

✅ **Simple & Interactive GUI** built with Tkinter.  

## 📌 How It Works  
- Clicking **"Music (Loop)"** starts Track A on repeat.  
- Clicking **"Red Light!!!"** plays Track B, stopping any other track.  
- Clicking **"Green Light"** plays Track C.  
- If Track C completes, Track A automatically starts looping.  
- Use **Pause** and **Resume** to control the music playback.
